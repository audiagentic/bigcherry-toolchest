# UI redesign v2

Visual pass driven by the rendered Builds page on a 1785x832 desktop viewport.

Goals:
- replace stock-Pico/cyan appearance with a restrained neutral workstation palette even for saved `dark` users;
- make navigation left-aligned and visually structured;
- constrain form width and restore hierarchy on wide screens;
- demote manual external-build registration to an advanced disclosure because BigCherry publication is normally automatic;
- keep all routes, htmx behavior, fields, IDs, and server behavior unchanged.
